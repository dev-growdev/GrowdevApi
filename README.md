# Growdev API

Esta é a **Growdev API**, uma API Rest desenvolvida com **.NET 8** na IDE **Visual Studio 2026**, criada especificamente para ser usada em um teste técnico de programação C#.

## Desafio do Candidato

O desafio do candidato é, em primeiro lugar, analisar o código já existente e entender o padrão de desenvolvimento e os recursos utilizados.

### Passos para começar:
1. Crie um novo branch a partir do branch `develop`.
2. Baixe esse novo branch em sua máquina.

> **Nota:** As instruções de qual deve ser o nome do branch e qual a tarefa que deve ser realizada serão enviadas por email.
